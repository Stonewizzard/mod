# Selected Ancient Anvil: Foundry (A)

Foundry is the selected production design. The ordinary Ancient Anvil item,
crafting recipe, Creative entry, default blockstate, inventory model and recovered
Foundry anvil all use the normal item. Its longer classic horn, slightly slimmer
waist and four narrow lava falls retain the reviewed A artwork exactly.

The separate A/B/C comparison items are hidden from Creative. Their registry IDs,
serialized design values and meshes remain available for existing stacks and
placed samples. Explicitly saved older variants keep their appearance; recovering
and replacing an old BASE anvil applies the selected design. No inventory or
neighboring block is erased to change artwork.

The original comparison remains a design reference:

| Previous sample | Horn and proportions | Corner lava |
| --- | --- | --- |
| A: Foundry (selected) | Longer classic horn, waist about 8% narrower | Four slender open streams into the corner cups |
| B: Spillways | Broad sturdy horn, original waist | Four wider waterfall sheets |
| C: Runic Columns | Long broad horn, waist about 15% narrower | Four framed falls |

All designs retain the eighteen-cell 3x3x2 reservation, Tier 0/Tier 1 foundation,
per-design collision and true mesh outline. Native UVs preserve pixel density.
The corner lava is an animated visual element. Compatibility tests retain all 288
part/orientation/design recovery paths and legacy footprint/container protection.
Native QA verifies the normal item places Foundry in survival, along with its
ordinary held model, all four facings, guide and day/night/profile captures.
